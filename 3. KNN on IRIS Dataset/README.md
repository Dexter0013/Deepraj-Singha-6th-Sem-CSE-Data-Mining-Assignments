# Iris Species Classification using KNN

This repository contains a machine learning project that classifies Iris flower species using the K-Nearest Neighbors (KNN) algorithm.

## Project Overview
The goal of this project was to build a robust classification model for the classic Iris dataset. The workflow involved data preprocessing, feature scaling, and visual evaluation.

## Key Features
- **Algorithm:** K-Nearest Neighbors (KNN)
- **Evaluation:** Comprehensive reporting including Accuracy, F1-Score, and a Confusion Matrix.

## Results
The final model achieved an accuracy of **100%** on the test set.
